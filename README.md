# Servet Rent A Car

Servet İnşaat Emlak Rent A Car için hazırlanmış Next.js web sitesi ve yönetim paneli.

## Geliştirme

```bash
npm install
npm run dev
```

- Web sitesi: `http://localhost:3000`
- İlanlar: `http://localhost:3000/ilanlar`
- Yönetim paneli: `http://localhost:3000/admin`

## Teknolojiler

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide Icons
